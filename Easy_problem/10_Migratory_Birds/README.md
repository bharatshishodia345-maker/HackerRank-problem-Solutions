# Migratory Birds

## Problem

Given an array representing bird types, find the bird type that occurs most frequently.

If multiple bird types have the same maximum frequency, return the smallest bird type.

## Approach

- Create a frequency dictionary.
- Count how many times each bird type appears.
- Find the maximum frequency.
- If two bird types have the same frequency, choose the smaller type.

## Complexity

- Time Complexity: O(n)
- Space Complexity: O(n)
